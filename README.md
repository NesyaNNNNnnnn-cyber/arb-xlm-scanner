# ARB XLM Scanner — MVP 0.1

Первая безопасная заготовка проекта. Она:
- получает публичные стаканы Bybit Spot для XRPUSDT и XLMUSDT;
- предоставляет `/health`;
- поддерживает Telegram-команды `/start`, `/help`, `/status`, `/scan`;
- предусматривает ежедневный технический отчёт в 21:00 Europe/Moscow;
- не совершает сделки, не выводит средства и не отправляет сигналы о прибыли.

## Важное ограничение

Полная цепочка XRP → XLM → USDT пока НЕ рассчитывается. Для этого нужно подключить конкретного провайдера обмена XRP→XLM из Trust Wallet и получать его свежую исполнимую котировку с комиссиями, лимитами и сроком действия. Пока провайдер не определён, любые проценты арбитражной доходности были бы выдуманными.

## Запуск

1. Установить Python 3.11+.
2. `pip install -r requirements.txt`
3. Скопировать `.env.example` в `.env` и заполнить `BOT_TOKEN`.
4. Запустить `python main.py`.
5. Открыть бота в Telegram и отправить `/start`.

Для ежедневного отчёта нужно также задать `CHAT_ID` — это числовой ID чата, в котором бот будет присылать отчёт. Не используйте токен бота в публичных файлах.

## Render

В репозитории есть `render.yaml`. При создании сервиса добавьте секреты `BOT_TOKEN` и `CHAT_ID` в Environment. Бесплатный Web Service Render может засыпать после периода без входящего трафика, поэтому этот тариф не обеспечивает надёжный мониторинг 24/7 и своевременные уведомления.
